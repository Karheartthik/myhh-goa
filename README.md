# HH Goa 2026
[🌐 Live Demo](https://myhh-goa.vercel.app/)

## A Modern Digital Experience for Goa

HH Goa 2026 is a modern, responsive web application developed as part of the **HH Goa 2026 Builder Studio Assignment**.

The project delivers an engaging digital experience inspired by Goa, combining modern UI/UX, immersive visuals, smooth interactions, responsive layouts, and a clean frontend architecture.

---

## ✨ Features

- 🌴 Goa-inspired visual design
- 🏖️ Modern and immersive user interface
- 📱 Fully responsive design
- ⚡ Fast and optimized frontend
- 🎨 Clean and modern UI/UX
- 🧩 Reusable React components
- 🖥️ Desktop, tablet, and mobile support
- 🔗 Smooth navigation and interactions
- 🚀 Production-ready build
- 🌐 Ready for web deployment

# 🚀 How to Run

## Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

Check the installations:

```bash
node --version
npm --version
git --version
```

---

## 1. Clone the Repository

```bash
git clone https://github.com/Karheartthik/myhh-goa.git
```

## 2. Navigate to the Project

```bash
cd myhh-goa
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start the Development Server

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:8080
```

If Vite displays a different port in the terminal, open the URL provided by Vite.

---

# 📦 Available Commands

### Start Development Server

```bash
npm run dev
```

Starts the application in development mode.

### Build for Production

```bash

```

Creates an optimized production build.

### Run Linter

```bash

```

Checks the project for code-quality and ESLint issues.
